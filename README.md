# 8085 Microprocessor Official Website

## About

This is the official landing page for the 8085 Microprocessor project, built to showcase the features and provide easy access to download the CLI tool. The project makes learning 8085 assembly programming modern, interactive, and enjoyable.

## Tech Stack

- **React** - UI framework
- **Vite** - Build tool and dev server
- **Tailwind CSS** - Utility-first CSS framework
- **Framer Motion** - Animation library
- **Lucide React** - Icon library
- **Shadcn UI** - Headless UI components

## Installation

```bash
# Clone the repository
git clone https://github.com/girisakar365/8085-Microprocessor.git
cd 8085-Microprocessor

# Switch to web branch
git checkout web

# Install dependencies
npm install

# Start development server
npm run dev
```

## Build

```bash
# Build for production
npm run build

# Preview production build
npm run preview
```
